# Carousel factory

## Input
A topic, URL, or pasted notes. Ask for audience and brand voice only if neither is obvious.

## Output
Write `carousel/<slug>/carousel.md` containing:

1. **Hook slide** — ≤ 8 words, one bold claim or question.
2. **Body slides (5–8)** — one idea per slide, ≤ 25 words each, headline + support line.
3. **CTA slide** — one action (save, follow, comment a keyword).
4. **Visual direction** per slide — layout, dominant color, image or icon idea. 1080×1350 portrait.
5. **Caption** — first line repeats the hook, 80–150 words, line breaks every 1–2 sentences.
6. **Hashtags** — 5–10, mix of broad and niche.

## Rules
- Each slide must make sense read alone; no "as mentioned above".
- No claims you cannot source from the input.
- Keep slide count between 7 and 10 including hook and CTA.
